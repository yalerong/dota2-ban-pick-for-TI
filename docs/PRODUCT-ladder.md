# 天梯 BP 副驾驶：产品简报

## 定位

一句话：**拍一张当前选人界面，立即告诉玩家这手最适合选什么，以及为什么。**

天梯是主产品。职业比赛模块提供训练数据、盲测证据和传播案例，不进入普通玩家的主要操作路径。

## 核心用户与任务

- 不想在短暂选人时间里查多个网站的天梯玩家。
- 知道自己打几号位，但无法同时判断克制、协同、阵容缺口和版本热度。
- 核心任务不是浏览数据，而是在数秒内得到一个明确、可解释、仍由玩家最终决定的候选英雄。

## 最小闭环

1. 用户打开页面，默认记住常玩位置。
2. 点击“拍照 / 导入截图”。
3. 系统识别公开画面中的随机禁用、双方已选英雄，并显示置信度。
4. 页面突出一个主推荐和三个备选，理由控制在三条以内。
5. 识别错误时，用户在折叠的纠错区点头像修改。
6. 后续有人选英雄时再次拍照，推荐自动更新。

真实头像识别接入前，演示版使用明确标注的“体验示例”完成同一条流程，不能把模拟结果描述成真实识别。

## 单屏信息层级

1. 主入口：拍照 / 导入截图。
2. 决策：一个主推荐，包含头像、名称、推荐强度和短理由。
3. 备选：三个紧凑候选。
4. 纠错：已选、禁用和位置，默认折叠。
5. 背书：版本、clean 职业赛样本量、盲测结果入口。
6. 职业训练：独立次级页，可分别选择我方和对手、交换双方、查看对阵摘要并进入模拟 BP。

## 60 秒演示

1. 打开页面，点击“体验一键识别”。
2. 示例状态自动填入，立即出现主推荐和三个备选。
3. 展开纠错区，模拟对手新增一名英雄。
4. 推荐和理由随阵容变化。
5. 切到“职业验证”，展示同一模型使用职业比赛数据训练和盲测。

## 成功指标

- 打开到看到推荐：小于 5 秒。
- 英雄识别 Top-1：达到 95% 后才宣传“自动识别”。
- 每局人工纠错：少于 2 次。
- 主推荐或备选采纳率。
- 次日/七日复用率。
- 推荐理由可理解率。

## 安全与合规边界

- 手机或第二屏读取用户本来可见的画面。
- 不读取游戏内存、隐藏数据或网络包。
- 不注入 Dota/Steam 进程，不修改游戏文件或 UI。
- 不自动点击、自动 ban/pick，也不替玩家执行输入。
- 不根据隐藏玩家身份做针对性 ban。
- 不暗示 Valve、Steam 或 Dota 官方授权。
- 商业发布实时天梯建议前，对 Steam Web API 的“不公平竞技优势”条款做专项合规审查。

## 暂不做

- 账号、社交、云端历史战绩。
- 复杂职业战队管理后台。
- 未经验证的胜率提升承诺。
- 没有真实截图样本时建设泛化视觉模型。
